# PlaceMux Enterprise Analytics

*Developed by Ritu Raj Singh*

## 📌 Project Overview

This project is based on *PlaceMux – White-Label Configurability & Admin Control Plane*.

The objective of this project is to build enterprise-level analytics that help customers understand their recruitment performance, business value, configuration impact, and areas for improvement.

The project focuses on:

* Recruitment Funnel Analysis
* Candidate Quality Analysis
* Time-to-Hire Analysis
* ROI Analysis
* Tenant Performance Analysis
* Configuration Impact Analysis
* Benchmark Analysis
* Actionable Recommendations
* Interactive Tableau Dashboard

## 🧹 Data Cleaning

The dataset was cleaned and validated using Python.

Main cleaning activities included:

* Checking dataset structure and data types
* Detecting missing values
* Removing duplicate records
* Cleaning column names
* Handling missing numeric values
* Handling missing categorical values
* Converting date fields
* Removing unwanted spaces
* Checking invalid and negative values
* Validating recruitment funnel metrics

## 📊 Analysis Performed

### Recruitment Funnel

The recruitment funnel was analyzed across:

*Applications → Screened → Interviewed → Offered → Hired*

Conversion rates were calculated to understand the movement of candidates through different recruitment stages.

### Candidate Quality

Candidate quality was analyzed using Quality Score and quality categories to understand overall recruitment quality.

### Time-to-Hire

Average Time-to-Hire was analyzed to identify hiring speed and compare performance across tenants and configurations.

### ROI Analysis

Hiring Cost and Revenue Value were used to calculate ROI and evaluate business value.

### Tenant Performance

Tenant-level analysis was performed using:

* Applications
* Hires
* Hire Rate
* Quality Score
* Time-to-Hire
* ROI

### Configuration Impact

The impact of different configurations was analyzed using:

* Auto Screening
* Interview Stages
* Approval Workflow

These configurations were compared with recruitment outcomes, especially Time-to-Hire and performance metrics.

### Benchmark Analysis

Overall performance benchmarks were calculated and tenant performance was compared against those benchmarks.

Recommendation flags were also created to identify areas such as:

* Improve ROI
* Improve Candidate Quality
* Reduce Time-to-Hire
* Improve Funnel Conversion

## 📈 Tableau Dashboard

An interactive *Enterprise Analytics Dashboard* was created in Tableau.

The dashboard contains:

* Total Applications KPI
* Total Hires KPI
* Hire Rate KPI
* Average Quality Score KPI
* Average Time-to-Hire KPI
* Overall ROI KPI
* Recruitment Funnel
* Tenant ROI Performance
* Quality vs Time-to-Hire
* Auto Screening Impact
* Interview Stage Impact
* Approval Workflow Impact

The dashboard is designed to provide a clear view of enterprise recruitment performance and help identify improvement opportunities.
